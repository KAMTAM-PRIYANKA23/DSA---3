Programs in DSA

1. Write a program that accepts n integers into an array and displays the array elements in reverse order. The first element should become the last, the second should become the second-last, and so on. Do not use any built-in reverse function. Example: Input: n = 4, elements 10 20 30 40 → Output: 40 30 20 10

2. Write a program that reads n integers into an array and finds both the largest and the smallest element in a single traversal of the array. Print the maximum and minimum values. Example: Input: n = 5, elements 5 2 9 1 7 → Output: Maximum = 9, Minimum = 1

3. Write a program that reads n integers into an array and a search key from the user. Search for the key by checking each element sequentially. If the key is found, print its position (index); otherwise, print that the element is not present. Example: Input: array 4 8 15 16, key 15 → Output: Element found at index 2

4. Write a program that reads n integers into an array and sorts them in ascending order using the bubble sort technique, in which adjacent elements are repeatedly compared and swapped if they are in the wrong order. Display the sorted array. Example: Input: 64 25 12 22 → Output: 12 22 25 64
5. Write a program that reads a string from the user and converts the case of each character — every uppercase letter is changed to lowercase and every lowercase letter is changed to uppercase. Characters that are not letters (such as digits, spaces, and symbols) remain unchanged. Display the resulting string. Example: Input: Hello World 123 → Output: hELLO wORLD 123

6. Write a program that reads a positive integer and repeatedly adds its digits until the result becomes a single digit (1–9). In each step, add all the digits of the current number; if the sum has more than one digit, repeat the process on that sum. Display the final single-digit result.
Example: Input: 9875 → 9+8+7+5 = 29 → 2+9 = 11 → 1+1 = 2 → Output: 2
